# Desvendando Matemática

## Sobre o projeto

O **Desvendando Matemática** é um projeto de material didático digital interativo para explorar conceitos matemáticos por meio de explicações, gráficos e experimentação.

A proposta é aproximar a explicação teórica da exploração visual dos conceitos. As funções e seus gráficos não aparecem apenas como ilustrações: os professores e estudantes podem interagir com as representações gráficas e observar como diferentes funções se comportam.

O projeto utiliza recursos interativos para transformar o estudo do cálculo em uma experiência mais exploratória, conectando **conceitos, representações gráficas e aplicações**.

## Conteúdo

### Módulo: Cálculo I

Este módulo aborda:

1. **Análise de gráficos via derivadas** (Interpretação da derivada a partir do gráfico)
2. **Teoremas de Rolle e do Valor Médio (TVM)**
3. **Testes da 1ª e 2ª Derivada**
4. **Síntese: esboço de gráfico completo**

## Proposta didática

O material busca trabalhar o cálculo a partir da relação entre diferentes formas de representação matemática, especialmente:

- interpretação gráfica;
- comportamento das funções;
- derivadas e suas interpretações;
- análise de crescimento e decrescimento;
- máximos e mínimos;
- concavidade;
- aplicação dos teoremas e testes;
- construção e interpretação de gráficos.

A interação com os gráficos permite modificar funções, observar seu comportamento e estabelecer relações entre a representação algébrica e a representação visual.

## Tecnologias

- **Python**
- **Streamlit** (principal framework para estruturação do conteúdo)
- **Plotly** (Renderização dos gráficos matemáticos interativos)
